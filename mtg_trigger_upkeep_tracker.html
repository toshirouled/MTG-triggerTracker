GitHub & Android Deployment Guide

This app is 100% client-side HTML/CSS/JS with local storage support. You can store your deck configs directly in GitHub or run as an Android APK.

Option 1: Deploy with GitHub Pages (Web / PWA)

  1. Create a repository on GitHub (e.g. mtg-trigger-tracker).
  2. Upload this index.html file.
  3. Go to Settings > Pages, select main branch and click Save.
  4. Open the hosted link on Android Chrome, tap "Add to Home Screen" to install as an offline App!

Option 2: Convert to Android APK (Capacitor)

To build an Android APK from your GitHub project:

npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "MTG Triggers" com.mtg.triggers
npx cap add android
npx cap open android

Storing Triggers in GitHub

Export your Deck Triggers as JSON via the Deck tab and store the .json file in your repo to share with playgroups or reload anytime.
